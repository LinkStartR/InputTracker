# Bootstrap 人工验收清单

## 前置条件

- 使用 Windows 10 或 Windows 11 x64 的普通用户账户。
- 从 `scripts/verify.ps1 -Stage Bootstrap` 生成的绿色发布目录启动。
- 在任务管理器中确认 PowerShell、终端和 InputTracker 均未以管理员身份运行。

## 人工步骤

1. 双击 `InputTracker.exe`，确认没有 UAC 提示，主窗口与托盘图标均出现。
2. 再次双击同一目录的 `InputTracker.exe`，确认没有第二个长期存活的 InputTracker 进程。
3. 从托盘选择暂停，确认窗口和托盘文案明确显示“已暂停”。
4. 从托盘选择恢复，确认状态恢复为“未采集”，且没有把当前安全外壳误称为已经采集。
5. 退出应用，等待 5 秒后在任务管理器中确认没有残留 InputTracker 进程。
6. 检查程序目录、用户 Startup 目录、注册表和用户数据目录，确认本阶段没有创建目录外数据、快捷方式、服务或注册表项。

## 证据

- 记录 Windows 版本、账户是否为普通用户、发布提交和验证证据 JSON 路径。
- 保存主窗口、托盘暂停、托盘恢复三张截图。
- 记录第二次启动前后的 InputTracker 进程数量和退出后的进程数量。
