# Portable 现场验收清单

- [ ] 使用未安装 .NET 的 Windows 10 x64 普通用户，从含中文和空格的可写绿色目录首次启动，不弹 UAC。
- [ ] 首次告知明确键盘/鼠标采集边界；拒绝时不采集、不写设置，允许后才启动采集。
- [ ] 开启随 Windows 启动后只创建当前用户 Startup 下 `InputTracker.lnk`；关闭后删除自有快捷方式，不覆盖或删除外来快捷方式。
- [ ] 用户暂停、锁屏和系统挂起原因独立叠加；解除一个原因不得清除另一个，barrier 返回前已接收事件已处理完。
- [ ] 系统注销/关机走受控停止路径；启动、暂停、恢复、退出后无残留进程。
- [ ] 运行前后检查程序目录、Startup、注册表、服务和本进程网络连接；除授权 Startup 快捷方式外，不得目录外写入、注册表、服务、提权或运行时联网。
- [ ] 展示数据位置与卸载说明；删除程序目录前明确提示先退出，用户数据只有用户主动操作才删除。

Startup、锁屏/挂起、真实硬件、Windows 10/11 与视觉检查任一未现场完成时，`releaseEligible` 必须为 `false`。
