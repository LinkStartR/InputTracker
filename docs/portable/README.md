# InputTracker 绿色版说明

## 数据与首次启动

InputTracker 的程序、配置、统计数据库、日志及备份均位于绿色版程序目录。首次启动会先说明采集边界；只有用户明确确认后，程序才会创建并启动 Storage 和 Raw Input。拒绝确认、配置损坏或未来版本配置均保持未采集，程序不会改用 AppData、Temp 或注册表。

键盘只累计设备、物理键、日期的次数与按住时长，不保存文字、事件顺序、窗口或进程。鼠标只累计左、右、中、侧键一和侧键二的按下次数，不保存移动位置、路线、滚轮或事件顺序。旧版本已经产生的轨迹文件不会被自动删除；如需清除，应先退出程序并另行确认历史数据处理范围。

## 随 Windows 启动

默认关闭。用户点击“启用开机启动”后，程序只在当前用户 Startup 目录创建 `InputTracker.lnk`，目标为当前运行的 `InputTracker.exe`。关闭时只删除目标仍精确指向当前程序的该快捷方式；同名但属于其他程序的文件、目录连接或符号链接均拒绝覆盖或删除。程序不写注册表、不安装服务、不请求管理员权限。

## 暂停与系统生命周期

用户暂停、锁屏和系统挂起是独立且可叠加的原因。解锁只移除锁屏原因，系统恢复只移除挂起原因，均不会清除用户主动暂停。Windows 注销或关机时，程序进入受控停止和释放路径。

## 卸载

1. 在 InputTracker 中点击“关闭开机启动”。
2. 点击“退出”，确认托盘图标及进程均已结束。
3. 如需保留数据，先复制整个绿色版程序目录作为备份。
4. 删除绿色版程序目录。不要在程序运行时移动或删除其中的数据文件。

Startup 快捷方式是唯一允许位于程序目录外的运行状态。若程序目录已被直接删除，应由用户手工删除当前用户 Startup 目录中遗留的 `InputTracker.lnk`。
